# Парсер PDF-выписки

Парсер рассчитан на текстовые PDF-выписки с шестью колонками, как в примере:

1. дата и время операции;
2. дата и время списания;
3. сумма в валюте операции;
4. сумма в валюте карты;
5. описание;
6. последние четыре цифры карты.

Алгоритм проходит по всем страницам, получает слова с координатами, объединяет их в визуальные строки и раскладывает по колонкам. Новая операция определяется по двум датам и двум суммам. Строки без дат присоединяются к предыдущей операции, поэтому многострочные описания сохраняются. Повторяющиеся заголовки и номера страниц отбрасываются.

Суммы преобразуются в целое число копеек. Время получает часовую зону `Europe/Moscow`. `external_id` строится из реквизитов операции через SHA-256, поэтому повторная загрузка той же выписки не создаёт дубликаты.

Использование из Python:

```python
from parser_pdf import parse_pdf

statement = parse_pdf(pdf_bytes)
full_json = statement.to_dict()
import_json = statement.to_import_dict(account_id="UUID-счёта-в-приложении")
```

Из PowerShell, находясь в каталоге `backend`:

```powershell
$env:PYTHONPATH = "src"
python -m parser_pdf statement.pdf --output statement.json
python -m parser_pdf statement.pdf --account-id UUID --output import.json
```

Второй вариант создаёт тело запроса для `POST /api/v1/imports`.

Ограничение: в PDF должен быть текстовый слой. Если выписка состоит из изображений, сначала нужен OCR. Такой файл завершается ошибкой `В PDF нет текстового слоя. Сначала выполните OCR`.
